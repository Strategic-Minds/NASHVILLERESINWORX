# APPROVAL MATRIX

## Status
Approval-controlled. Autonomous posting, email/SMS sending, ad spend, pricing changes, schema changes, environment changes, and governance changes are disabled unless Jeremy explicitly approves.

## Level 0: Automatic Internal Work
Allowed without approval:
- Trend discovery
- Topic research
- Competitor research
- Hashtag research
- Script drafts
- Caption drafts
- Topic scoring
- Analytics summaries
- Internal documentation

## Level 1: Prepare Only
Allowed as drafts only:
- Metricool-ready schedule files
- Klaviyo email drafts
- Shopify product content drafts
- Website copy drafts
- Avatar generation prompts
- Content edits

## Level 2: Human Review Required
Requires Jeremy review before use:
- Scheduled posts
- Final captions
- Final videos
- Final images
- Email campaigns
- Lead follow-up responses
- Product descriptions
- Website page copy

## Level 3: Explicit Jeremy Approval Required
- Public publishing
- Sending email/SMS
- Paid advertising
- Shopify pricing/discount changes
- Product launches
- Public warranty/timeline/price claims
- External integrations

## Level 4: Governance-Locked
Requires exact current-session command:
- Supabase schema changes
- Vercel environment variables
- Billing
- API keys
- GitHub workflow mutation
- Governance/source-truth changes
- Autonomous posting enablement

## Escalation Rule
When uncertain, stop and route to APPROVAL_CENTER.md.
